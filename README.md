# Paradise Nursery Shopping Cart

## Project Overview
Paradise Nursery is an online plant shopping application where users can browse houseplants, explore different categories, and add plants to a shopping cart.

## Features
- Landing page with company information.
- Browse houseplants organized into categories.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- View individual plant costs and the total cart amount.
- Navigate between the home page, product listing, and shopping cart.

## Technologies Used
- React
- Redux Toolkit
- JavaScript
- HTML
- CSS

## Project Purpose
This project demonstrates a plant shopping application using React components, Redux Toolkit for state management, and interactive shopping cart functionality.
